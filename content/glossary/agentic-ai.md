An **AI agent** combines a large language model with access to tools: an ERP API, a document store, an email account or a messaging channel. Given a goal, it decides which steps to take, calls the tools it needs, checks the results and continues until the task is done or it needs a person.

## How is it different from a chatbot?

A chatbot responds to messages. An agent can *act*: look up an order, draft a quotation, update a record or route a request. That makes agents more useful, but it also means they need clearer limits.

## What makes an agent safe to use in a business?

- **Narrow permissions.** The agent can only read and change what its task requires.
- **Human approval** for risky actions such as sending money, changing prices or emailing customers.
- **Logs** of every step, so people can review what happened.
- **Evaluation** against real examples before and after launch.
