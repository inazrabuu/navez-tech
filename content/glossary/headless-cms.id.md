Pada CMS tradisional, seperti WordPress versi klasik, konten, template dan server yang menampilkan halaman menjadi satu paket. CMS **headless** hanya menyimpan dan mengedit konten; website dibangun terpisah dan mengambil konten dari CMS tersebut.

## Mengapa perusahaan memilih CMS headless atau berbasis Git?

- **Cepat.** Halaman bisa dibuat lebih dulu sebagai file statis dan disajikan dari jaringan global, sehingga tetap cepat di koneksi seluler.
- **Aman.** Tanpa database atau halaman login admin di website publik, celah yang bisa diserang jauh lebih sedikit.
- **Mudah untuk editor.** Tim marketing mendapat layar edit yang rapi tanpa risiko merusak tata letak.
- **Bisa dipakai ulang.** Konten yang sama bisa dipakai untuk website, aplikasi atau kanal lain.

## Apa itu CMS berbasis Git?

Varian headless CMS yang menyimpan konten sebagai file di repository Git, bukan di database. Setiap perubahan punya versi, bisa ditinjau, dan mudah dikembalikan. Cocok untuk website perusahaan, dokumentasi dan blog.
